# Stalwart SCIM Provisioning Connector

Independent WSO2 Identity Server 7.3.0 outbound provisioning connector for Stalwart.

Baseline: WSO2 SCIM outbound connector 5.4.1 (Apache-2.0). The custom connector will use an independent Java package, OSGi bundle identity, and connector type (`stalwart-scim`).

Status: implementation and CI build are in progress. No installable JAR is published yet.
